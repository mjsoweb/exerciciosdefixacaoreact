📌 Questões Teóricas 05

1.Qual a diferença entre herança e sobrescrita de métodos?

Herança é a capacidade de uma classe filha reaproveitar atributos e métodos da classe pai. Sobrescrita é quando a classe filha recria um método herdado para alterar ou personalizar o seu comportamento.

2.Para que serve a palavra-chave super?

Serve para acessar e chamar métodos ou o construtor diretamente da classe pai a partir de uma classe filha.

3.Qual a vantagem de reutilizar métodos da classe pai?

Evita repetição de código, reduz a chance de erros e garante que as regras básicas fiquem centralizadas em um único lugar.

4.Por que utilizar atributos privados (#)?

Para proteger os dados contra alterações indevidas feitas por fora da classe, obrigando o uso de métodos com validações (setters).

5.Qual a diferença entre != e !==?

!= compara apenas se os valores são diferentes (com conversão automática de tipo).

!== compara se os valores OU os tipos de dados são diferentes (é uma comparação estrita e mais segura).

6.Qual a função do método includes()?

Verifica se um determinado texto ou caractere existe dentro de uma string, retornando true ou false.

7.Em que situação a sobrescrita é mais indicada do que criar um método completamente novo?

Quando a ação a ser executada tem o mesmo conceito/objetivo (ex: alterar o e-mail), porém a classe filha exige regras de validação adicionais ou diferentes da classe pai.
