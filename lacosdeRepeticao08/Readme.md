Respostas das Questões Teóricas Laços de Repetiçao 08

1.Qual a principal diferença entre os laços for e while?

O laço for junta a inicialização, a condição de parada e o incremento em uma única linha, sendo ideal quando sabemos a quantidade exata de iterações. O laço while testa a condição antes de cada repetição e é mais indicado para situações onde o número de repetições não é fixo.

2.Em qual situação o laço do...while é mais indicado?

Quando precisamos garantir que o bloco de código seja executado pelo menos uma vez antes da checagem da condição (por exemplo, na exibição de menus onde a opção do usuário precisa ser lida pelo menos uma vez).

3.Qual a vantagem do laço for...of quando trabalhamos com arrays?

Ele possui uma sintaxe mais limpa e direta para acessar cada elemento do vetor sem precisar controlar variáveis de índice (i) ou usar a propriedade length.

4.Para que serve a propriedade length?

Retorna o número total de elementos contidos em um array.

5.O que acontece se esquecermos de atualizar a variável de controle em um laço while?

Ocorre um loop infinito, fazendo com que o programa fique preso executando o laço sem parar até travar a aplicação.

6.Qual estrutura você considera mais adequada para percorrer um array? Justifique sua resposta.

Depende do objetivo: o for...of é o mais adequado se você só precisa ler ou manipular os valores contidos no array de forma limpa. Se você precisar da posição/número do índice de cada item, o for tradicional é o mais indicado.

7.Em quais situações é necessário utilizar o índice dos elementos de um array?

Quando precisamos exibir a posição/número de cada item (ex: Aluno 1, Aluno 2).
