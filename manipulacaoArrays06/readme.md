📌 Questões Teóricas 06

1.O que é um array?

É uma estrutura de dados (uma coleção ordenada) usada para armazenar múltiplos valores dentro de uma única variável.

2.Como os elementos de um array são organizados?

São organizados de forma sequencial através de posições numéricas chamadas índices, sendo que a contagem sempre começa na posição 0.

3.Qual a diferença entre push() e unshift()?

push() insere um novo elemento no final do array.

unshift() insere um novo elemento no início do array (reorganizando todos os índices seguintes).

4.Qual a diferença entre pop() e shift()?

pop() remove e retorna o elemento que está no final do array.

shift() remove e retorna o elemento que está no início do array.

5.Para que serve a propriedade length?

Serve para retornar o número total de elementos presentes no array.

6.Como acessar o último elemento de um array sem informar um índice fixo?

Utilizando a fórmula array[array.length - 1]. Como os índices começam em zero, o índice do último item sempre será o tamanho total menos 1.

6.Por que utilizar arrays em vez de criar uma variável para cada informação?

Porque os arrays facilitam a organização e manutenção do código, permitindo manipular grandes quantidades de dados com loops e métodos reutilizáveis, sem ter que criar centenas de variáveis manuais (livro1, livro2, livro3...).
